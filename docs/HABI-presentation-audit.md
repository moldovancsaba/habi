# HABI / HABI2 presentation audit

23 October 2026

## Implemented contract

All text content and text-based interactions align to the start edge. This includes primary and secondary actions, answer choices, skip/back/later controls, assessment cards, tabs, disclosures, fields, native selects and bottom navigation. Athlete message bubbles sit on the right; text inside them stays start-aligned. Icons and icon-only selectors centre within their own boxes. Metric colours and square geometry are retained.

`global.css` is the only application stylesheet. Templates and logic supply semantic classes, structure, behaviour and data. SVG path/viewBox/coordinate geometry remains in source as artwork or plotted data; fill, stroke, stroke width, chart-point size, text anchors, palette and type are CSS-driven. Browser theme metadata reads the CSS page token. The web manifest no longer duplicates palette colours.

The computed-style fixture audit checks the full state set under the shared stylesheet, including content inside collapsed fixture wrappers. It is supplemented by visual and interactive browser checks of selected live views; it is not a claim that every combination was manually reviewed on physical devices. Temporary review fixtures are excluded from the production commit.

## Maintenance

New components must use the same alignment rule, CSS tokens and shared component helpers. Do not restore the previous centred-action/start-aligned-answer split. Any exception needs a semantic purpose, such as an icon-only control or SVG chart annotation; page-specific text alignment is not an exception. Keep the component reference and README aligned with the implementation.
