# HABI journey structure

The four athlete tabs keep their existing names and icons. `experience.js` owns screen composition and return context; all new copy is stored in MongoDB-backed `experience_v1`. Existing assessment, practice, reflection, chat and goal records remain the source of truth.

| User intention | Home in HABI | What appears there | Way forward / back |
| --- | --- | --- | --- |
| How am I today? | Kezdőlap | Today's real check-in or its summary; one unfinished-work card | Start/check result; return to Kezdőlap |
| Continue unfinished work | Kezdőlap | One priority continuation: goal draft, practice, chat, monthly or reflection draft | Resume exact draft; never label completed chat as unfinished |
| Work on what I chose | Feladataim | Active chosen goal, relevant daily support, existing regular habit | Practise, review or choose a practice |
| Find something useful to try | Feladataim → Gyakorlatok | Ten unique exercises; all explanations grouped under their related exercise | One exercise action per card; return to its real source |
| Talk about something | HABI | Seven topic choices and an optional collapsed group of concrete situations | One conversation home, current conversation resumes |
| Talk about today's answers | Daily result → HABI | Existing assessment-linked conversation, clearly identified by date | Same HABI navigation and message components |
| Understand patterns | Fejlődésem → Áttekintés | Period filter and one chart; combined or one-metric mode | Only the selected interpretation/chart is visible |
| Revisit a specific day | Fejlődésem → Naplóm | Canonical daily records and their original messages, practice/reflection/chat events | Open dated records; write evening/weekly reflection |
| Reflect over a month | Fejlődésem → Hónapjaim | One due/resume invitation and separate original monthly records | Start/resume or open saved result; return to same section |
| Revisit an earlier goal | Feladataim / Naplóm → Korábbi vállalásaim | Existing goal archive | Open the original goal and related events |
| Change preferences | Kezdőlap → Beállításaim | Example preference and optional reminders | Return to Kezdőlap |

## Grouping rules

Home does not reproduce the task library, development dashboard, evening/weekly buttons or a second conversation picker. It shows only the real assessment for today; sample history never becomes today's completed check-in. Monthly invitations respect deferral. The morning reminder reuses the existing daily action instead of creating another button for it.

Tasks do not contain settings or monthly reflection. A regular habit remains separate from a time-bounded experiment, but both remain optional. Pain-related daily guidance takes precedence over a goal practice suggestion. The library contains ten practice identities, not a second parallel list of twelve learning entrances. Existing explanations remain available within related exercises and their original guide routes remain compatible.

HABI owns generic and situation-led conversations. The old `situations` route forwards to the HABI starter. Contextual daily conversations retain their exact assessment ID and identify that context visibly. No athlete text, diagnosis, assessment score or stored conclusion is regenerated by this reorganisation.

Development has three explicit sections. Overview never renders two copies of the chart. Diary shows the existing dated records and activity snapshots. Monthly reflection has one start/resume action; the empty state never adds a duplicate action. The goal archive is a deliberate secondary page, not another large block among charts.

## Orientation and return context

A current-tab state is always present: assessment/result/settings belong to home; practice/library/goals belong to tasks; reflections/monthly/archive belong to development; conversations belong to HABI. Subpages have a quiet location trail within main content, with a parent action and current page label. This does not add a branded top bar.

Practice drafts retain their source page, monthly record ID and development section/chart/period. Completing or skipping a practice returns to that source. Goal drafts also retain their source: declining a goal returns to the originating practice result or exact monthly record. A parent-navigation action preserves a goal draft; explicit cancellation removes only the draft. Historical records are not removed. The existing monthly resume logic, saved practice instructions and chosen-conversation wording remain unchanged.

## Verification

Automated checks cover focused home, dedicated task/library/settings ownership, one visible chart, separate diary/monthly sections, single monthly invitation, navigation selection, practice return context, goal cancellation/source fidelity, HABI ownership and all pre-existing assessment/chat/storage tests. Browser verification passed on 320px and 375px frames: focused home, settings and its return, ten-exercise library, completion → goal offer → cancellation → original exercise → library, unified HABI situation entry, separate development sections, single metric chart → practice → restored chart mode, and evening reflection → completion → dated diary. Neither tested viewport overflowed horizontally. Monthly entry and its existing question controls were also checked. This verifies the implemented journey contract; it does not substitute for observing children using the product.
